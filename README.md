# 📘 Thesis Open Access

Ce dépôt met à disposition plusieurs ressources utiles dans le cadre de travaux de recherche en sciences humaines et en statistiques :

## 📄 Guide du chercheur

Un document complet présentant les principales méthodologies statistiques utilisées en recherche. Il offre des explications théoriques, des exemples pratiques et des recommandations pour une application rigoureuse des analyses.

## 🧪 Expérience PsyToolkit

Un fichier ZIP contenant le script PsyToolkit permettant d'utiliser la catégorisation des distances. Il inclut l’ensemble des éléments nécessaires pour importer, lancer et adapter l’expérience.

## 📊 Script R d’analyse

Un script R prêt à l’emploi pour analyser les données issues de l’expérience. Il comprend le nettoyage des données, les analyses statistiques principales ainsi que la génération de graphiques.
